# Spring Nest (春日小筑) 项目实际可用性说明

## 项目定位

Spring Nest 是一个**纯前端、零后端依赖**的 Web 应用，可作为：
- 个人工具集合站
- 前端面试作品展示
- PWA 离线应用
- 小程序/App 的 WebView 内嵌页面

## 上线的必要准备

1. **PWA 图标**: 制作 192x192 和 512x512 PNG 图标放入 `public/`
2. **域名**: 绑定自定义域名
3. **HTTPS**: PWA 需要 HTTPS（本地 localhost 除外）

## 设计系统

项目采用 Material Design 3 启发的颜色体系：
- Primary: 春日绿 (#3f6751)
- Tertiary: 温暖棕 (#795648)
- Surface: 温暖米白 (#FFF9F2)
- 完整支持暗色模式

风格定位：Spring Nest (春日小筑) — 治愈系、温暖、柔和、日系简约风格
