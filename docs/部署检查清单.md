## Vercel 部署

### 方式一：CLI 部署
```bash
# 1. 安装 Vercel CLI
npm install -g vercel

# 2. 登录
vercel login

# 3. 部署到生产环境
vercel --prod
```

### 方式二：Git 集成
1. 将代码推送到 GitHub/GitLab/Bitbucket
2. 登录 [vercel.com](https://vercel.com)
3. 点击 "New Project"
4. 导入仓库
5. Vercel 自动检测 Vite 项目，无需额外配置
6. 点击 "Deploy"

### Vercel 配置说明
- `vercel.json` 中的 `rewrites` 确保 SPA 路由正常工作
- 静态资源（`/assets/`）设置 1 年强缓存
- Service Worker（`sw.js`）设置不缓存，确保更新及时生效

### 验证 Vercel 部署
- [ ] 首页加载正常
- [ ] 直接访问 `/games` 等子路由不返回 404
- [ ] 浏览器前进/后退按钮正常工作
- [ ] PWA 安装提示出现
- [ ] 离线访问正常
- [ ] 环境变量 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY` 已配置
- [ ] Supabase 连接正常 (登录/注册功能可用)

## SPA 路由验证

### 测试步骤
1. 访问首页 `/`
2. 通过导航进入子页面（如 `/games/2048`）
3. **刷新页面** — 应正常加载，不返回 404
4. **直接在地址栏输入子路由** — 应正常加载
5. 使用浏览器前进/后退按钮 — 应正常导航
6. 测试以下路由：
   - `/games`
   - `/games/2048`
   - `/tools`
   - `/tools/calculator`
   - `/favorites`
   - `/profile`
   - `/about`
   - `/search?q=test`

### 常见问题
| 问题 | 原因 | 解决方案 |
|---|---|---|
| 刷新返回 404 | 服务器未配置 SPA 回退 | 检查 `vercel.json` 或 `_redirects` |
| 白屏 | 资源路径错误 | 检查 `vite.config.ts` 中的 `base` 配置 |
| 路由跳转后 404 | 使用了 `BrowserRouter` 但服务器未配置 | 确保部署配置正确 |
