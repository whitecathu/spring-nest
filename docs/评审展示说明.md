# Spring Nest 评审展示说明

## 项目概述

Spring Nest（春日小筑）是一个汇集实用工具与休闲小游戏的 PWA Web 应用。项目从一个 AI Studio 静态 Demo 出发，经过三轮系统化改造，成为具备真实功能、完整用户体系、工程化配置的可上线产品。

## 核心亮点

### 1. 真实功能，零占位符

项目中每一个按钮、每一个交互都有真实行为。5 个工具（计算器、番茄钟、单位换算、密码生成器、二维码生成器）全部可正常使用，3 个游戏（2048、记忆翻牌、打地鼠）全部可玩。没有模拟下载、没有假数据卡片、没有空按钮。

### 2. 完整用户系统

基于 localStorage 实现的本地用户系统，包含：
- 邮箱格式校验 + 密码长度校验的注册流程
- 登录状态持久化（刷新页面不丢失）
- 按用户 ID 隔离的收藏功能
- 个人中心展示用户信息与主题设置

### 3. 现代技术栈

| 技术 | 版本 | 用途 |
|---|---|---|
| React | 19 | UI 框架 |
| Vite | 6 | 构建工具 |
| TypeScript | 5.8 | 类型安全 |
| Tailwind CSS | 4 | 原子化样式 |
| React Router | 6 | 客户端路由 |
| Motion | 12 | 动画引擎 |
| Vitest | 4 | 单元测试 |
| Playwright | - | E2E 测试 |

### 4. 工程化配置

- **CI/CD**: GitHub Actions 自动运行 lint、单测、构建、E2E
- **代码分包**: React.lazy 页面级懒加载，首屏只加载必要代码
- **PWA**: Service Worker 离线缓存，支持安装到桌面
- **双平台部署**: Vercel（vercel.json）+ Netlify（_redirects）配置就绪
- **测试覆盖**: 82 个单元测试 + Playwright E2E 测试

### 5. 用户体验

- 中英双语切换（覆盖全部页面）
- 暗色/浅色/跟随系统三种主题模式
- 移动端触屏适配（2048 滑动、打地鼠点击）
- ErrorBoundary 全局错误兜底
- 404 页面友好提示
- 搜索支持名称、描述、分类、标签全文检索

## 技术架构

```
┌─────────────────────────────────────────────┐
│                  用户浏览器                    │
├─────────────────────────────────────────────┤
│  React 19 + React Router 6                  │
│  ├── pages/        页面组件（懒加载）          │
│  ├── components/   公共组件                   │
│  ├── contexts/     全局状态（User + Theme）    │
│  ├── hooks/        自定义 Hooks               │
│  ├── services/     业务逻辑（纯函数）          │
│  ├── data/         静态数据                   │
│  └── types/        TypeScript 类型            │
├─────────────────────────────────────────────┤
│  localStorage 持久化层                       │
│  ├── 用户账号 + 登录状态                      │
│  ├── 收藏数据（按用户隔离）                    │
│  ├── 游戏成绩 + 工具偏好                      │
│  └── 语言 + 主题设置                         │
├─────────────────────────────────────────────┤
│  Vite 6 构建 + Tailwind CSS 4               │
│  PWA (Service Worker + Manifest)             │
└─────────────────────────────────────────────┘
```

## 代码质量

### 类型安全
全项目 TypeScript strict 模式，无 `any` 泛滥。数据层有独立的 `types/app.ts` 和 `types/user.ts`，所有组件 props 和 service 函数都有明确类型标注。

### 测试策略
- **单元测试** (Vitest): authService、favoriteService、searchService、2048 核心逻辑、单位换算，共 82 个用例
- **E2E 测试** (Playwright): 首页加载、导航路由、工具使用、游戏交互、登录注册、收藏、搜索、主题切换、404 页面

### 构建产物
- 总 JS ~526KB，gzip 后 ~160KB
- 页面级代码分包，首屏加载更快
- PWA 离线缓存，二次访问秒开
