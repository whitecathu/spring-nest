# Spring Nest 演示脚本

> 总时长约 15 分钟，按顺序演示即可。

---

## 1. 项目简介（1 分钟）

大家好，这是 Spring Nest（春日小筑），一个汇集实用工具与休闲小游戏的 PWA Web 应用。

它提供 5 个真实可用的效率工具和 3 个可玩的休闲小游戏，支持中英双语、本地账号系统、收藏功能、暗色主题和离线访问。

项目从一个 AI Studio 静态 Demo 出发，经过三轮系统化改造，所有功能都是真实可用的，没有占位符、没有假按钮。

---

## 2. 技术栈介绍（1 分钟）

技术栈方面：

- React 19 做 UI 框架，Vite 6 做构建工具
- TypeScript 5.8 保证类型安全，Tailwind CSS 4 做原子化样式
- React Router 6 处理客户端路由，支持浏览器前进后退
- Motion（Framer Motion）做动画，Lucide React 做图标
- Vitest 做单元测试，82 个测试用例全部通过
- Playwright 做 E2E 端到端测试
- GitHub Actions 做 CI，每次 push 自动跑 lint、测试、构建、E2E
- PWA 支持离线访问和安装到桌面

## 4. 登录注册演示（2 分钟）

点击右上角"登录"按钮，弹出登录弹窗：

**注册流程：**
- 输入邮箱（演示输入错误格式，如 `abc`，展示邮箱校验提示）

**登录流程：**
- 退出登录后，再次打开登录弹窗

**持久化演示：**
- 刷新页面，登录状态保持

## 演示注意事项

1. 提前确保 `npm run dev` 已启动，页面正常加载
2. 提前注册一个测试账号，避免演示时出错
3. 准备好暗色/浅色主题各截图一张，以防现场切换出问题
4. 如果网络不稳定，PWA 离线演示可以提前录屏
5. 游戏演示建议提前练习几次，避免演示时操作失误
