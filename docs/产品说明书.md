# 春日小筑 (Spring Nest) - 产品说明书

## 1. 产品概述 (Product Overview)

**春日小筑 (Spring Nest)** 是一款汇集休闲游戏与实用工具的综合性 Web 平台。产品旨在为用户提供一个“藏尽春日好物，聚齐实用与欢喜”的数字空间，通过现代化、极简而温馨的用户界面（UI），让用户在繁忙的生活中找到片刻的放松（游戏天堂）与便捷的辅助功能（实用小筑）。

## 2. 目标用户 (Target Audience)

- **休闲玩家**：寻找轻松、随玩随走的小游戏（如：森林漫步、拼图、打地鼠等）的用户。
- **效率追求者**：需要快速访问各类计算器、单位换算、密码生成等实用工具的用户。
- **现代 Web 应用体验爱好者**：喜欢流畅动画、精致排版和响应式设计的用户。

## 3. 核心功能结构 (Core Features)

### 3.1 首页 (Home)

- **欢迎横幅**：带有温馨的欢迎语和流畅的微动画特效，营造“春日”氛围。
- **快速导航卡片**：提供「游戏天堂」与「实用小筑」两大核心模块的大尺寸入口卡片，配合交互特效引导用户。
- **最新动态/应用推荐**：以跑马灯或卡片轮播的形式展示最新上架的游戏和工具。

### 3.2 游戏天堂 (Games)

- **游戏分类**：支持多维度分类（如：全部、益智、休闲、动作等）过滤。
- **游戏列表**：以美观的图片卡片展示游戏缩略图、标题、描述和热度。
- **体验特色**：沉浸式的悬停缩放效果，清晰的“开始游戏”引导。

### 3.3 实用小筑 (Tools)

- **工具分类**：支持（全部、效率、开发、生活等）类别快速切换。
- **工具列表**：采用玻璃拟物化 (Glassmorphism) 卡片风格，展示计算器、单位换算等工具。
- **详情展示**：提供工具的具体用途说明和直观的图标。

### 3.4 收藏夹 (Favorites)

- 用户可以将常用的游戏或工具加入收藏。
- 提供专属面板，便于快速访问已收藏的内容，支持移除操作。

### 3.5 个人中心 (Profile / 账号管理)

- **资料管理**：修改用户名、个人简介、联系邮箱。
- **偏好设置**：
  - **国际化 (i18n)**：中英双语一键切换。
  - **主题切换**：支持深色/浅色模式（系统级适配）。
- **设备与安全**：查看当前登录设备，支持修改密码、注销账号和退出登录。
- **消息通知**：管理系统通知、系统更新等订阅偏好。

### 3.6 侧边抽屉导航 (Navigation)

- 全局导航栏（顶部），支持全局搜索、收藏快速入口。
- 侧边全局菜单：响应式适配移动端，提供平滑的划出/收起动画。

## 4. 技术架构 (Technical Architecture)

本产品属于完全的纯客户端单页应用 (SPA)。

- **前端框架**：React 18 (基于 Hooks 和 Functional Components)
- **构建工具**：Vite (提供极速的热更新和打包构建体验)
- **路由管理**：自定义轻量级状态路由 (currentPage) 结合 Context API。
- **状态管理**：React Context API (UserContext) 处理全局的用户态、语言、偏好。
- **样式方案**：Tailwind CSS (原子化 CSS 构建响应式与定制化 UI)。
- **动画引擎**：Motion / Framer Motion (实现页面切换、布局变更、微交互的流畅动画)。
- **图标库**：Lucide React (提供统一规范、可高度定制的矢量图标)。
- **惰性加载**：使用 `React.lazy` 和 `Suspense` 对各个路由页面进行代码分割 (Code Splitting)，提升首屏加载速度。

## 5. UI/UX 设计理念 (Design Philosophy)

- **色彩心理学**：采用温暖的春日色调（如：柔和的绿色、温暖的奶油色、桃粉色及宁静的蓝色）作为主背景和主功能色。
- **流畅动效**：去除繁冗的滤镜(Blur)，使用快速而轻量的位移与透明度变化 (`easeOut`, 0.3s) 进行过渡，拒绝“拖泥带水”。
- **一致性**：所有的卡片圆角 (rounded-2xl/3xl)、阴影 (shadow-sm/md) 和按钮交互均保持全站一致。
- **响应式**：完美适配 Desktop、Tablet (iPad) 和 Mobile 尺寸，确保无论在何种设备上内容均清晰易读、导航顺畅。

## 6. 未来规划 (Roadmap)

- **Phase 1 (MVP)**：完成前端核心框架、页面展示、动画交互及基础工具/游戏的静态展示。 _(当前阶段)_
- **Phase 2**：引入后端服务 (如 Node.js/Express) 或 Serverless 数据库整合，实现真实的用户注册、数据云同步、动态加载真实游戏。
- **Phase 3**：扩展社交功能，支持用户评论、评分游戏/工具，以及分享到第三方平台。
- **Phase 4**：推出 PWA (Progressive Web App) 版本，提供原生应用级别的沉浸感及离线使用能力。
