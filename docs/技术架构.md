# Spring Nest (春日小筑) 技术架构

## 概述

Spring Nest 是一个纯前端 Web 应用，汇集实用工具与休闲小游戏。使用 React 19 + TypeScript + Vite 构建，所有数据通过 localStorage 在浏览器端持久化。

## 技术栈

| 技术                   | 版本  | 用途            |
| ---------------------- | ----- | --------------- |
| React                  | 19    | UI 框架         |
| TypeScript             | 5.8   | 类型安全        |
| Vite                   | 6     | 构建工具        |
| Tailwind CSS           | 4     | 原子化 CSS 框架 |
| React Router           | 6     | 客户端路由      |
| Motion (Framer Motion) | 12    | 动画库          |
| Lucide React           | 0.546 | 图标库          |
| qrcode                 | 1.5   | 二维码生成      |
| Vite PWA Plugin        | 1.2   | PWA 离线支持    |
| Vitest                 | 4     | 单元测试        |

## 路由设计

| 路径            | 页面          | 说明                             |
| --------------- | ------------- | -------------------------------- |
| `/`             | Home          | 首页                             |
| `/games`        | Games (列表)  | 游戏列表                         |
| `/games/:slug`  | Games (详情)  | 游戏详情（如 /games/2048）       |
| `/tools`        | Tools (列表)  | 工具列表                         |
| `/tools/:slug`  | Tools (详情)  | 工具详情（如 /tools/calculator） |
| `/favorites`    | Favorites     | 收藏列表                         |
| `/profile`      | Profile       | 个人中心                         |
| `/about`        | About         | 关于我们                         |
| `/search?q=xxx` | SearchResults | 搜索结果                         |
| `*`             | NotFound      | 404 页面                         |

## 数据流

```
┌─────────────────────────────────────────┐
│              React Context              │
│  ┌───────────┐  ┌───────────────────┐   │
│  │UserContext │  │   ThemeContext     │   │
│  │(user,lang)│  │(light/dark/system) │   │
│  └─────┬─────┘  └────────┬──────────┘   │
└────────┼──────────────────┼─────────────┘
         │                  │
    ┌────▼────┐        ┌───▼────┐
    │ Services │        │  DOM   │
    │(pure fn) │        │(class) │
    └────┬────┘        └────────┘
         │
    ┌────▼────┐
    │localStorage│
    └─────────┘
```

- **Context 层**：UserContext 管理用户状态和语言；ThemeContext 管理主题
- **Service 层**：纯函数，操作 localStorage，不依赖 React
- **数据流向**：Service → Context → Hook → Component

## localStorage 存储键

| Key                           | 内容         | 格式                                |
| ----------------------------- | ------------ | ----------------------------------- |
| `spring_nest_users`           | 注册用户列表 | JSON (`UserAccount[]` 含密码)       |
| `spring_nest_current_user`    | 当前登录用户 | JSON (不含密码)                     |
| `spring_nest_favorites`       | 收藏数据     | JSON (`{[userId]: string[]}`)       |
| `spring_nest_lang`            | 语言偏好     | `'zh'` \| `'en'`                    |
| `spring_nest_theme`           | 主题偏好     | `'light'` \| `'dark'` \| `'system'` |
| `spring_nest_2048_best`       | 2048最高分   | number                              |
| `spring_nest_memory_best`     | 记忆翻牌最佳 | number                              |
| `spring_nest_whackamole_best` | 打地鼠最高分 | number                              |
| `spring_nest_pomodoro`        | 番茄钟统计   | JSON                                |

## 主题系统

使用 Tailwind CSS v4 的 `dark:` variant + CSS 自定义属性实现：

1. ThemeContext 管理 `mode` (light/dark/system)
2. `system` 模式监听 `prefers-color-scheme` 媒体查询
3. 切换时给 `<html>` 添加/移除 `dark` class
4. CSS 文件中通过 `.dark` 选择器覆盖 CSS 变量
5. 组件中使用 `dark:` 前缀适配暗色模式

## 构建优化

- React.lazy + Suspense 实现页面级代码分割
- 手动 chunk 分组：react-vendor, motion, lucide, qrcode
- 游戏/工具组件按需懒加载
- qrcode 库仅在二维码页面加载
