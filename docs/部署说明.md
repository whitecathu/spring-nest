# Spring Nest (春日小筑) 部署说明

## 本地运行

### 前置要求
- Node.js 18+

### 安装与启动
```bash
# 1. 安装依赖
npm install

# 2. 开发模式启动
npm run dev
# 访问 http://localhost:3000

# 3. 生产构建
npm run build

# 4. 预览构建产物
npm run preview
```

### 可用命令

| 命令 | 说明 |
|---|---|
| `npm run dev` | 启动开发服务器 (端口 3000) |
| `npm run build` | 生产构建到 dist/ |
| `npm run preview` | 预览构建产物 |
| `npm run test` | 运行单元测试 |
| `npm run lint` | TypeScript 类型检查 |

## Supabase 项目设置

### 1. 创建 Supabase 项目

1. 访问 [supabase.com](https://supabase.com) 并注册/登录
2. 点击 "New Project" 创建新项目
3. 选择组织、输入项目名称和数据库密码
4. 选择离用户最近的区域

### 2. 获取 API 密钥

在 Supabase Dashboard → Settings → API 中获取:

- **Project URL**: `https://your-project.supabase.co`
- **Anon Key**: `eyJhbGciOiJIUzI1NiIs...` (公开密钥，受 RLS 保护)

### 3. 初始化数据库

在 Supabase Dashboard → SQL Editor 中执行 [RLS-SQL.md](./RLS-SQL.md) 中的 SQL 脚本:

1. 执行第 1 节 (扩展)
2. 执行第 2-6 节 (建表 + RLS)
3. 执行第 7-8 节 (触发器)
4. 执行第 9 节 (视图)
5. 执行第 10 节 (授权)

### 4. 配置认证

在 Supabase Dashboard → Authentication → Settings 中:

1. 设置 **Site URL**: `https://your-domain.com`
2. 添加 **Redirect URLs**:
   - `https://your-domain.com/**`
   - `http://localhost:3000/**` (本地开发)
3. 启用邮箱确认 (生产环境建议开启)

### 5. 配置 CORS

在 Supabase Dashboard → Settings → API → CORS Origins 中添加:

```
https://your-domain.com
https://your-project.vercel.app
http://localhost:3000
```

详见 [安全规则.md](./安全规则.md)。

## 部署到静态托管

构建产物在 `dist/` 目录，可部署到任何静态托管服务。

### Vercel

项目根目录已包含 `vercel.json`，自动处理 SPA 路由回退和静态资源缓存。

```bash
npm install -g vercel
vercel --prod
```

或直接导入 GitHub 仓库，Vercel 会自动检测 Vite 项目。

**配置说明**：`vercel.json` 包含：
- `rewrites` — 将所有路由重写到 `index.html`（SPA 路由支持）
- `headers` — 静态资源 1 年缓存，Service Worker 不缓存

### Netlify

项目 `public/` 目录已包含 `_redirects` 文件，构建时自动复制到 `dist/`。

1. 将 `dist/` 目录拖入 Netlify 部署页面
2. 或连接 Git 仓库，构建命令设为 `npm run build`，发布目录设为 `dist`

**配置说明**：`_redirects` 包含 `/* /index.html 200`，确保所有路由返回 index.html（200 状态码）。

### GitHub Pages

使用 GitHub Actions:

```yaml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

### Cloudflare Pages

1. 连接 Git 仓库
2. 构建命令: `npm run build`
3. 构建输出目录: `dist`

### 自托管 (Nginx)

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/spring-nest/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

## PWA 注意事项

- PWA 图标文件 `pwa-192x192.png` 和 `pwa-512x512.png` 需要放置在 `public/` 目录
- 可以先用占位图标，部署前替换为正式图标
- Service Worker 通过 `vite-plugin-pwa` 自动生成

## 环境变量

项目使用以下环境变量:

| 变量名 | 说明 | 必需 |
|---|---|---|
| `VITE_SUPABASE_URL` | Supabase 项目 URL | 是 |
| `VITE_SUPABASE_ANON_KEY` | Supabase 匿名密钥 | 是 |

### 配置步骤

1. 复制 `.env.example` 为 `.env`
2. 填入 Supabase 配置 (从 Supabase Dashboard → Settings → API 获取)
3. 重启开发服务器使环境变量生效

```bash
cp .env.example .env
# 编辑 .env 文件，填入 Supabase 配置
npm run dev
```

### Vercel 环境变量

1. 在 Vercel Dashboard → Settings → Environment Variables 中添加:
   - `VITE_SUPABASE_URL` = `https://your-project.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = `your-anon-key`
2. 选择环境: Production / Preview / Development
3. 重新部署以使环境变量生效

### Netlify 环境变量

1. 在 Netlify Dashboard → Site settings → Environment variables 中添加:
   - `VITE_SUPABASE_URL` = `https://your-project.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = `your-anon-key`
2. 重新部署以使环境变量生效

## SPA 路由注意事项

由于使用 React Router 的客户端路由，服务器需要配置将所有路由重定向到 `index.html`。以上所有部署方案均已包含此配置。

## 数据库迁移

### 从 localStorage 迁移到 Supabase

如果用户之前使用 localStorage 存储数据，首次登录 Supabase 时会自动迁移:

1. 用户登录 Supabase 后，系统检查 localStorage 中是否有旧数据
2. 如果有，将 localStorage 数据批量写入对应的 Supabase 表
3. 迁移完成后，标记迁移状态，后续使用 Supabase 作为数据源
4. localStorage 保留为离线缓存

### 手动迁移脚本

如需手动迁移数据，可在浏览器控制台执行:

```javascript
// 导出 localStorage 数据
const data = {
  favorites: JSON.parse(localStorage.getItem('spring_nest_favorites') || '{}'),
  scores: {
    '2048': localStorage.getItem('spring_nest_2048_best'),
    'memory': localStorage.getItem('spring_nest_memory_best'),
    'whackamole': localStorage.getItem('spring_nest_whackamole_best')
  }
};
console.log(JSON.stringify(data, null, 2));
```

### 数据库备份

Supabase 提供自动备份功能:

1. 在 Supabase Dashboard → Database → Backups 中查看
2. 免费计划: 7 天自动备份
3. Pro 计划: 30 天自动备份 + PITR
