# 复习小筑复习工作台体验优化设计

Status: Ready for user review
Date: 2026-05-17

## 背景

复习小筑当前已经具备本地题库解析、内置题库、粘贴导入、题库管理、错题、收藏、刷题、背答案、解析浏览和本地复习记录等能力。但产品体验仍偏向“文件导入工具”，用户打开后需要自己判断下一步做什么，移动端也容易被导航、说明、卡片和表单挤满。

本次优化采用“方案 A”的核心思路，但不做付费、Pro、订阅或商业化展示，也不把产品设计成每日打卡系统。目标是把复习小筑做成一个实用复习工具：用户可以随时导入、随时抽查、随时继续、随时考前速刷，而不是被每日目标绑住。

## 产品原则

1. 默认展示“复习”，不是“今日打卡”。
   产品可以显示建议队列和学习状态，但文案避免“今日必须完成”“连续打卡”“未完成压力”。

2. 强调工具实用性。
   首页核心是继续复习、随机抽查、错题重练、背答案、考前速刷、导入题库，而不是学习成就墙。

3. 移动端优先。
   复习动作必须单手可达。题干、选项、答案和下一题操作要比说明文字更重要。

4. 本地可信。
   继续突出浏览器本地解析和本地保存，不夸大 PDF、OCR、Excel 或云同步能力。

5. 少装饰，多信息结构。
   保留春日小筑的柔和气质，但减少大面积卡片堆叠和重复说明，让界面更像可长期使用的学习工具。

## 竞品借鉴

- Quizlet 和 Knowt 的优势是学习模式清楚，用户不用先理解文件结构就能开始学。
- Anki 和 RemNote 的优势是复习队列和主动回忆，用户打开后知道下一张卡是什么。
- Brainscape 的优势是用“掌握程度/置信度”替代简单对错，让复习节奏更贴合记忆。
- 国内背诵类产品的优势是任务入口明确、错题回流直接、考前复习路径短。

复习小筑不复制它们的打卡和订阅逻辑，只吸收“打开即复习”“错题回流”“复习反馈可见”“移动端操作短路径”。

## 信息架构

### 顶部导航

保留五个主入口，但调整默认心智：

- 复习: 默认入口，显示工作台和常用复习动作。
- 导入: 文件、内置题库、粘贴文本、备份 JSON。
- 题库: 搜索、筛选、编辑、整理。
- 错题: 错题回看、移出错题、重练。
- 设置: 本地数据、导出、支持格式和复习偏好。

现有 `AppView` 可以从 `import | bank | review | wrong | settings` 扩展或重新映射。推荐新增 `home` 或 `workbench`，避免把复习会话页和复习工作台都塞进 `review`。

### 默认入口

加载本地数据后：

- 有可继续的复习会话时，优先展示“继续上次”。
- 有题库但没有会话时，展示“开始复习”和“随机抽查”。
- 没有题库时，展示一个短路径导入面板，提供“预览内置题库”“选择文件”“粘贴题库”。

不使用“今天还差 N 题”作为主标题。可以保留设置中的每日题量作为“建议数量”，但文案改为“本次建议 N 题”或“快速复习 N 题”。

## 核心界面

### 复习工作台

复习工作台是第一屏主体，替代当前导入页首屏。

关键区域：

- 主行动区: 继续上次、开始复习、随机抽查。
- 快速队列: 错题重练、薄弱题、收藏题、考前速刷。
- 状态摘要: 题库总数、错题数、未复习数、平均掌握度、预计用时。
- 最近导入: 显示最近 2-3 个来源文件，方便用户判断题库是否正确。
- 导入入口: 只放轻量按钮，不在第一屏展开大表单。

移动端：

- 第一屏只保留标题、状态胶囊、一个主按钮和 3-4 个快捷动作。
- 导入说明和格式边界后移，不占首屏。
- 底部导航不与复习会话底部操作栏抢空间。

### 导入页

导入页继续保留现有能力，但减少解释密度。

推荐结构：

- 顶部为文件拖拽/选择。
- 第二块为粘贴文本。
- 第三块为内置题库。
- 解析预览只在识别到内容后展开。
- 支持格式说明收纳到折叠区或设置页。

导入成功后不强制跳到题库列表，推荐显示“开始复习”“查看题库”“继续导入”三种动作。

### 题库页

题库页从“所有题卡瀑布流”优化为“整理工具”。

保留：

- 搜索、筛选、排序。
- 编辑、删除、收藏、加入错题。
- 无限滚动。

新增或强化：

- 批量复习当前筛选结果。
- 当前筛选结果摘要。
- 移动端筛选抽屉和操作抽屉继续保留，但主按钮文案更短。

### 复习会话页

复习会话页是最影响留存的页面。

桌面端：

- 题干卡片更聚焦，减少顶部说明。
- 模式切换保留，但不抢主视觉。
- 统计区从大卡片改为轻量条或侧边摘要。

移动端：

- 顶部只显示进度、题型和模式。
- 题干和选项占主要空间。
- 底部固定操作栏根据状态变化：
  - 未答题: 上一题、标记、提交/显示答案、下一题。
  - 已答题: 错题、收藏、下一题。
  - 背答案: 重来、模糊、掌握。
- 支持左右滑动，但不能妨碍按钮、输入框和滚动。

### 错题页

错题页应像一个快速修复工具。

- 顶部展示错题数、重复错题数、最近错题。
- 主按钮是“错题重练”。
- 每张错题显示错因相关数据：错几次、上次错题时间、掌握度。
- 提供“已掌握，移出错题”。

## 复习逻辑

本次不引入复杂第三方算法，保持本地、可解释、易测试。

推荐在现有 `ReviewMeta` 基础上逐步加入：

- confidence: 用户主观掌握度，1-5。
- intervalDays: 当前复习间隔。
- dueAt: 建议下次复习时间。
- lapses: 反复遗忘次数。
- lastResult: remember | vague | forgot | correct | wrong。

初始规则：

- 回答正确或点“掌握”: 提高掌握度，延长间隔。
- 点“模糊”: 小幅降低掌握度，短间隔回流。
- 回答错误或点“重来”: 写入错题，次日或短期优先出现。
- 随机抽查不强制遵守 dueAt，满足工具型使用场景。

## 文案方向

避免：

- 今日还差 N 题
- 连续复习 N 天
- 完成打卡
- 解锁 Pro
- 付费体验

推荐：

- 继续上次复习
- 快速抽查
- 错题重练
- 考前速刷
- 本次建议
- 预计用时
- 本地保存
- 先预览，再导入

## 实现范围

第一轮实现建议聚焦：

1. 新增复习工作台组件，作为复习小筑默认入口。
2. 调整导航，把“复习”指向工作台，把实际刷题会话作为工作台触发后的状态。
3. 改写 `StudyCommandCenter`，移除“今日还差”和打卡式文案。
4. 优化移动端首屏和复习会话底部操作栏。
5. 调整导入页的信息顺序，减少首屏说明。
6. 为工作台摘要和复习队列补充单元测试。
7. 用 Playwright 检查桌面和 390px 手机宽度。

不做：

- 付费、订阅、价格页、Pro 标识。
- 云同步、登录依赖、后端接口。
- PDF/OCR/Excel 的伪支持。
- 题库市场或内容售卖。

## 测试计划

- 单元测试:
  - 复习队列摘要。
  - 掌握度、错题、模糊、重来等记录更新。
  - 空题库、有题库、有上次会话三种工作台状态。

- E2E:
  - 打开复习小筑，空题库能看到导入短路径。
  - 导入内置题库后能从工作台开始复习。
  - 移动端复习页底部操作可点击且不遮挡题干。
  - 题库页筛选后可以复习当前结果。

- 视觉检查:
  - 桌面 1440px。
  - 手机 390px。
  - 检查无横向滚动、无文字挤压、主按钮首屏可见。

## 自检

- 无付费或 Pro 范围。
- 无每日打卡压力文案。
- 默认体验从导入工具改为复习工具。
- 移动端主路径明确。
- 现有本地解析和存储边界保持真实。
