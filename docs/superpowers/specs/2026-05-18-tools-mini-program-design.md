# 春日小筑工具小程序设计

Date: 2026-05-18

## Summary

本设计把春日小筑的小程序方向定义为一个独立的工具小程序。它只包含现有 29 个工具，不包含任何游戏入口，也不要求当前 Web 端同步适配移动端。现有 React/Vite Web 继续保留工具与游戏；小程序以新的三 Tab 信息架构、微信小程序式页面栈、原生权限流和工具工作台重新设计。

用户已确认的关键决策：

- 采用原生小程序独立重构路径，不用 WebView 包装当前站点。
- 小程序只做工具，不做游戏。
- 底部 Tab 使用：首页、工具、我的。
- 复习小筑不单独占 Tab，但作为高权重工具出现在首页和学习写作分类。
- Web 端当前体验保持，不为了小程序改造而重写 Web 移动端。

## Research Basis

本设计参考了微信小程序与移动端通用交互约束，并结合当前代码库的工具能力做取舍。

- 微信小程序官方文档：WXSS/rpx、分包、性能建议、胶囊按钮与自定义导航相关 API，作为后续实现时的小程序平台边界。
- Tencent WeUI / WeUI WXSS：参考微信生态下的移动控件心智、反馈样式和轻量组件方向。
- WCAG 2.2 与 Android Accessibility：触控目标、可恢复交互和无障碍命名。
- MDN / web.dev 表单资料：移动输入场景下使用合适键盘、输入类型和表单反馈。

本项目当前已有 29 个工具、PWA、本地存储、搜索、收藏、题库和记账等能力。小程序设计应复用工具算法、文案和测试样例，但 UI、页面栈、权限、文件、相机、定位、剪贴板和保存相册等平台能力应按小程序重写。

## Goals

1. 建立一个清晰的小程序产品形态。
   用户打开后看到的是工具箱，而不是当前网站的缩小版。

2. 让每个工具都有手机端专属任务流。
   高频工具 1 到 2 步可以开始使用；复杂工具通过内部工作流拆解。

3. 保持 Web 与小程序的边界。
   Web 不迁就小程序重构，游戏也不进入小程序。

4. 为后续实现提供可落地的组件、数据流、错误处理和验收标准。

## Non-Goals

- 不在小程序中提供 19 个游戏。
- 不用 WebView 直接嵌入当前站点。
- 不在本轮设计中实现代码。
- 不强制引入账号或云同步。
- 不把复习小筑做成单独 Tab 或学习 App 入口。

## Information Architecture

小程序底部只保留三个一级 Tab：

### 首页

首页负责快速开始任务。

内容包括：

- 搜索工具。
- 最近使用。
- 收藏工具。
- 高频工具入口。
- 继续上次任务，例如上次账本、上次题库、上次城市或最近文件。
- 推荐分组，例如计算、文本、文档、学习、开发、日常。

首页不放营销式介绍，也不放游戏推荐。首屏应优先让用户打开工具。

### 工具

工具页负责完整目录。

目录包含 29 个工具，并支持：

- 全部工具。
- 最近使用。
- 收藏。
- 分类筛选。
- 搜索。

分类仍可沿用当前产品心智，但在小程序中更强调任务：

- 日常实用：计算器、单位换算、二维码、指南针、扫描仪、天气、IP 查询、小费、BMI、本地记账。
- 时间效率：番茄钟、倒计时与秒表、日期计算器。
- 文本学习：字数统计、Markdown 预览、文本对比、大小写转换、文字朗读、复习小筑。
- 开发辅助：JSON 格式化、Base64 编解码、URL 编解码、颜色转换。
- 文档转换：Word 转 PDF、PDF 转 Word。
- 随机趣味：随机选择器、随机数生成、随机文本生成。
- 安全隐私：密码生成器。

### 我的

我的页负责非任务型设置。

内容包括：

- 本地数据管理。
- 收藏和最近使用管理。
- 题库与记账备份导出。
- 隐私说明。
- 主题与语言设置。
- 反馈入口。
- 可选账号能力入口，但账号不能阻断核心工具使用。

## Tool Workbench Types

29 个工具按手机任务流归为 6 类模板，而不是每个工具单独设计一套页面骨架。

### 1. 快算快填

适用工具：

- 计算器
- 单位换算
- 小费计算器
- BMI 计算器
- 日期计算器
- 随机数生成

模板特征：

- 主输入在首屏。
- 结果即时出现。
- 常用预设用横向 chips 或分段控制。
- 数字输入使用数字键盘。
- 结果字段支持点击复制。

### 2. 文本处理

适用工具：

- 字数统计
- Markdown 预览
- JSON 格式化
- Base64 编解码
- URL 编解码
- 大小写转换
- 文本对比
- 随机文本生成
- 文字朗读

模板特征：

- 移动端不用桌面左右分屏。
- 使用编辑、结果、历史或预览分段。
- 底部固定复制、清空、交换、格式化等动作。
- 长文本输入保留草稿，但敏感工具不自动保存。
- 错误定位贴近输入区域。

### 3. 文件与设备

适用工具：

- 轻量扫描仪
- 二维码生成器
- 指南针
- 微风天气
- IP 查询
- Word 转 PDF
- PDF 转 Word

模板特征：

- 先处理相机、定位、传感器、文件选择和保存相册权限。
- 权限说明要短、明确、贴近动作。
- 权限失败后提供替代路径。
- 文件工具显示文件大小、处理状态、限制说明和结果保存入口。

### 4. 专注计时

适用工具：

- 番茄钟
- 倒计时与秒表

模板特征：

- 大数字为首屏核心。
- 开始、暂停、继续、重置在底部主操作区。
- 常用时长和模式切换使用 chips 或分段控制。
- 离开页面后通过时间戳恢复状态。
- 提醒以低打断为主。

### 5. 本地数据

适用工具：

- 本地记账
- 复习小筑

模板特征：

- 有内部仪表盘、列表、筛选、新增或导入、导出。
- 数据默认保存在本机。
- 提供导出备份和清理入口。
- 不默认云同步。
- 首屏显示继续任务和最近状态。

### 6. 安全隐私

适用工具：

- 密码生成器
- 所有涉及敏感输入的本地处理工具

模板特征：

- 明确本地处理和不上传。
- 生成结果不自动保存。
- 复制后只显示短 Toast。
- 敏感输入不进入最近内容明文展示。

## Shared Components

### ToolShell

统一工具页外壳。

职责：

- 工具标题。
- 返回。
- 收藏。
- 最近状态。
- 隐私说明入口。
- 帮助入口。
- 页面安全区。

ToolShell 不展示大段使用说明。说明应折叠到帮助入口或底部说明区。

### BottomActionBar

底部安全区上方的固定主操作区。

职责：

- 主动作，例如开始、生成、转换、保存、复制。
- 次动作，例如清空、交换、重置。
- 根据状态切换按钮文案。
- 避开小程序底部 Tab 和安全区。

### PermissionCard

统一权限说明组件。

覆盖：

- 相机。
- 定位。
- 传感器。
- 保存相册。
- 文件选择。
- 剪贴板。

状态：

- 未授权。
- 授权中。
- 已授权。
- 被拒绝。
- 无设备能力。
- 可用替代路径。

### ResultCard

统一结果卡片。

覆盖：

- 成功结果。
- 可复制字段。
- 警告。
- 错误。
- 空状态。
- 最近结果。

### SegmentTabs

用于同一工具内部视图切换。

例子：

- 编辑 / 预览。
- 输入 / 结果。
- 概览 / 明细。
- 文件 / 粘贴。
- 刷题 / 错题 / 导出。

### PresetChips

用于常用值快速选择。

例子：

- 小费比例。
- 倒计时时长。
- 单位类别。
- 随机数范围。
- Markdown 常用语法。
- 文本模板。

## Detailed Tool Design

### 计算器

首屏是结果显示、键盘和历史入口。单手可达区域优先放数字键、等号和清除。历史记录用底部抽屉展示，结果可点击复制。小程序不需要复刻 Web 的说明卡片。

### 番茄钟

首屏是大计时数字、当前模式和底部开始按钮。预设时长、长休息和声音设置放到底部面板。离开小程序后用开始时间、持续时间和状态恢复计时。

### 单位换算

先选择换算类别，再输入数值。常用单位置顶，结果以列表卡片显示，每行可复制。单位搜索用于长列表，常用组合可加入收藏。

### 密码生成器

长度使用滑杆与数字步进器，字符类型用开关。结果显示强度条和复制按钮。默认不保存生成历史；复制后只提示已复制。

### 二维码生成器

输入文本或链接后即时生成预览。提供放大预览、保存到相册和复制内容。链接可自动识别并给出 URL 类型提示。

### 指南针

先请求传感器能力。成功后显示罗盘和角度；失败时显示手动罗盘和校准提示。保留“无权限也能查看方向说明”的降级内容。

### 轻量扫描仪

首屏提供拍摄和从相册选择两个主动作。拍摄后进入裁剪、滤镜、增强和保存流程。保存需要相册权限；权限失败时提示用户改用分享或重新授权。

### 微风天气

首次打开请求定位，同时提供城市搜索兜底。缓存上次城市和上次天气，离线时展示缓存时间。天气详情使用卡片，不做过长信息瀑布流。

### 随机选择器

选项以逐行输入或 chips 管理。提供常用模板，例如吃什么、抽签、小组分配。抽取结果用轻动画呈现，并支持复制或再次抽取。

### 倒计时与秒表

用分段控制切换倒计时和秒表。倒计时提供 1、3、5、10、25 分钟等快捷值。秒表支持分圈记录，主按钮固定在底部。

### 字数统计

输入区占首屏主要空间。统计结果固定在下方摘要栏，展开后看中文字符、英文单词、行数、段落数等详细指标。

### Markdown 预览

使用编辑、预览、HTML 三段视图。编辑视图提供常用语法快捷栏；预览视图全屏阅读；HTML 输出可复制。移动端不使用左右分栏。

### JSON 格式化

输入 JSON 后可格式化、压缩和校验。错误提示包含行列信息和局部预览。结果视图支持复制、折叠层级和清空。

### Base64 编解码

输入和输出分为两个区域，编码/解码用分段或双按钮切换。支持交换输入输出。错误提示贴近输入区域。

### URL 编解码

与 Base64 共用输入输出模板，但提供 URL 复制、decode 错误提示和链接识别。结果可一键复制。

### 颜色转换器

提供取色、常用色板和格式卡片。HEX、RGB、HSL 分别作为可复制字段。色板不占首屏主操作，作为展开区。

### 日期计算器

使用日期选择器和数字步进器。支持日期差、日期推算和今天快捷。结果显示日期、星期、间隔天数，可加入最近。

### 文本对比

移动端分步输入原文和新文，结果页展示差异摘要和高亮列表。长文本对比避免左右分栏，提供只看新增、只看删除、全部差异。

### 随机文本生成

段落数、每段句数和经典开头使用步进器或开关。生成结果可复制、重新生成和清空。最近生成不默认保存长文本。

### IP 查询

打开后自动查询公网 IP，并提供刷新。字段点击复制。网络失败时显示失败原因和重试入口。

### 小费计算器

金额输入使用数字键盘。小费比例用 chips，多人分账用步进器。结果区固定显示小费、总额、人均金额。

### 大小写转换

输入文本后选择转换模式 chips。结果页显示转换文本、统计和复制。支持清空和交换。

### 随机数生成

范围、数量和是否允许重复用简单表单。常用预设包括骰子、1 到 10、1 到 100。历史结果可以折叠查看。

### BMI 计算器

身高、体重使用数字输入。结果显示 BMI、等级、范围和非医疗化提示。避免制造诊断结论。

### 文字朗读

输入文本后选择语言、语速和音色。播放、暂停、继续在底部操作区。若小程序能力不支持某些语音参数，应隐藏不可用选项。

### Word 转 PDF

通过小程序文件选择器选择 docx。显示文件大小、转换状态、限制说明和结果保存。复杂排版保留限制提示。大文件可先设本地限制，再预留服务端转换。

### PDF 转 Word

选择文本型 PDF 后提取文本并生成文档。明确扫描件和 OCR 限制。结果提供保存和分享入口。大文件和无文本 PDF 要有可恢复提示。

### 复习小筑

作为高权重工具，但不做一级 Tab。内部包含导入、题库、复习、错题、导出五段流程。首页卡片显示继续复习、题目数和最近题库。导入支持粘贴文本和文件；复杂压缩包解析需评估小程序本地能力，必要时降级或预留后端解析。

### 本地记账

首屏优先记录一笔支出或收入。月度概览放在上方摘要卡；明细和分类统计放在内部视图。导出 CSV 作为数据安全入口。默认本地保存，不自动云同步。

共享层优先抽取纯函数和测试样例，不抽取 React 组件。

可共享：

- 单位换算表和换算函数。
- JSON/Base64/URL/日期/BMI/随机数等纯逻辑。
- 记账统计函数。
- 题库解析中与平台无关的文本解析逻辑。
- 工具元数据、标题、描述和隐私说明。

小程序独立实现：

- 页面与组件。
- 路由和页面栈。
- 相机、定位、传感器、文件、剪贴板、保存相册。
- storage 封装。
- Toast、Modal、ActionSheet。
- 小程序包体和分包配置。

## Data Flow

1. 用户从首页、工具目录或最近记录进入工具。
2. ToolShell 加载工具元数据、最近状态和本地设置。
3. 工具通过表单、文件、相机、定位或传感器获取输入。
4. 本地纯逻辑优先处理结果。
5. ResultCard 展示结果、错误或警告。
6. BottomActionBar 提供复制、保存、下载、继续或清空。
7. 最近记录只保存必要摘要，敏感内容不明文记录。

## Error Handling

- 权限未开：解释用途，提供重新授权和替代路径。
- 输入错误：贴近字段提示，保留用户输入。
- 文件过大：显示限制、原因和降级方案。
- 转换失败：说明可能原因，允许重新选择文件。
- 设备不支持：显示替代入口，例如上传图片替代拍摄。
- 离线：本地工具继续可用，联网工具显示缓存或联网提示。
- 剪贴板失败：提示手动选择复制。

## Privacy And Storage

默认策略是本地优先。

- 工具输入默认不上传。
- 敏感结果不进入历史。
- 复习小筑和本地记账保存到小程序本地存储或文件缓存。
- 提供导出备份。
- 提供清理本地数据入口。
- 云同步可以作为未来扩展，但不进入本轮设计。

## Testing And Acceptance

设计验收：

- 小程序三 Tab 为：首页、工具、我的。
- 小程序无游戏入口。
- 复习小筑是高权重工具，但不是一级 Tab。
- 29 个工具都有小程序专属任务流。
- 首屏不展示大段说明，优先任务输入或继续入口。
- 主操作固定在底部安全区上方。
- 触控目标按 44/48px 级别设计。
- 所有可交互控件都有清晰文本或可访问名称。
- 权限失败、输入错误、文件过大、离线状态都有可恢复路径。

实现验收：

- Web 构建和测试不因小程序目录引入而退化。
- 共享纯函数有单元测试。
- 至少覆盖首页、工具目录、我的页和 3 个代表性工具的交互测试。
- 文档和文件工具有大小限制测试。
- 复习小筑和记账有本地导入导出测试。

## Open Implementation Decisions

这些不是设计阻塞项，但需要在实施计划中定细节：

- 使用原生微信小程序工程，还是先用可编译到小程序的框架。当前设计推荐原生小程序优先。
- 文档转换是否完全本地完成，还是设置本地限制并预留后端转换。
- 复习小筑压缩包和 docx 解析在小程序端的可行范围。
- 是否引入云同步。当前设计默认不做。
