OG Image Placeholder
====================

The index.html references /og-image.png for social sharing previews.

To complete this:
1. Convert og-image.svg to og-image.png (1200x630px)
   - Use any SVG-to-PNG tool (Figma, Inkscape, sharp, etc.)
   - Or design a custom image with the Spring Nest branding
2. Place the resulting og-image.png in this /public directory

The SVG placeholder uses:
- Background: #3f6751 (theme green)
- Card: #FFF9F2 (warm white)
- Title: "Spring Nest / 春日小筑"
- Subtitle: "实用工具与休闲小游戏"

Recommended: Add spring-themed illustrations (flowers, leaves, etc.)
to make the social card more visually appealing.
